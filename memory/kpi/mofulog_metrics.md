# mofulog KPI指標

mofulogの主要KPIを記録する。CEOまたはAI社員が定期的に更新する。
数値のスナップショットは`memory/kpi/kpi_snapshots/`に保存し、
このファイルには「今わかっている最新の状態」を記載する。

## 計測開始後の運用ルール

- リリース後、週次で上記テーブルを更新する
- 更新のたびに`services/kpi_memory_service.py`の`save_snapshot()`でスナップショットを保存し、変化を追跡できるようにする
- 自動計測・自動更新はまだ実装していない（MVPのため手動運用）
