# DAF Organization

> **DAF OS v2 — AI Company Phase**（Quest100〜）
> Quest1〜99は **DAF OS v1 — Foundation Phase** として位置づける（詳細は本ページ末尾「DAF Version」参照）。

Quest100は新機能の追加ではなく、Quest1〜99で積み上げてきた基盤を
「AI社員が協働するデジタル企業」として正式に定義し直すQuestである。

---

## Mission

AI社員が協働し、人間の創造性を何倍にも拡張するデジタルファクトリーをつくる。

## Vision

CEOは「何を作るか」を決める。
AI社員は「どう作るか」を考える。

CEOが日々行っているのは、Vision策定・意思決定・優先順位付け・最終承認であり、
それ以外の実務（コーディング・デザイン・市場調査・品質確認）はAI社員へ委譲する
（詳細は [docs/ceo_handbook.md](./ceo_handbook)）。

---

## Core Values

- CEO decides.
- AI collaborates.
- Build → Measure → Learn.
- Learn from every project.
- Quality before quantity.
- Automation with purpose.
- Every project becomes company knowledge.

# AI Company Workflow

```
Idea
  ↓
Nova       （市場調査・トレンド分析）
  ↓
Sirius     （プロダクト企画・UX方針）
  ↓
Vega       （Creative Brief・Character Bible・Style Guide・Prompt）
  ↓
Atlas      （Execution Plan・Image Generation Pipeline）
  ↓
Cosmos     （AI Workflow・Model/Renderer選定）
  ↓
Orion      （進捗管理・品質チェック）
  ↓
CEO Approval
  ↓
Publish
  ↓
Reflection
  ↓
Memory
  ↓
Next Product
```

現在のDAF OSで実装済みの経路との対応（参考）：

| Workflowの段階 | 対応する実装 |
|---|---|
| Idea | Project作成（services/project_service.py、Quest93） |
| Nova / Sirius | Strategic Goal・Initiative（Quest76〜77）、Product Planning（今後拡張） |
| Vega | Creative Brief（services/creative_brief_service.py、Quest99） |
| Atlas | Execution Planner（Quest88）、Image Generation Service / Renderer（Quest98） |
| Cosmos | Company Memory・AI経営会議（memory_service.py） |
| Orion | Weekly Board Meeting（Quest82）、Reflection Report（Quest61） |
| CEO Approval | CEO Decision Center（Quest81）、Artifact Review Center（Quest91） |
| Publish | stickers.zip等の成果物ダウンロード |
| Reflection → Memory | Reflection Service、Company Memory（Quest50） |
| Next Product | 新規Project作成へ戻る |

# DAF Departments

## Executive Board
CEO / Orion (COO) / Atlas (CTO) / Sirius (CPO) / Nova (CMO) / Cosmos (CIO) / Vega (CDO)

## Product Division
Lead: Sirius (CPO)
Product Planning・UX・Target定義を担当。現時点では専任のAI社員は未配置で、
Sirius自身がこの領域を担う。

## Creative Division
Lead: Vega (CDO / Chief IP Designer)
Members: Lyra (Content Creator) / Nebula (Video Producer) / IP Team（Luna・Sol・Astra、後述）
Creative Direction・Character Bible・Style Guide・Prompt Designに加え、
LINEスタンプ・ブログ・動画等のコンテンツ実制作を担う（Digital Asset Crew参照）。
Quest104〜105のIP Intelligence Sprintでは、IP Memory・IP Bibleの領域を
IP Team（後述）が担当する体制を明文化した。

## Engineering Division
Lead: Atlas (CTO)
Members: Polaris (App Engineer) / Pulsar (Automation Engineer)
アーキテクチャ・AI Pipeline・Infrastructureの設計と、アプリ開発・自動化処理の実装を担う。

## Marketing Division
Lead: Nova (CMO)
市場調査・トレンド分析・競合分析・Go-to-Marketを担当。現時点では専任のAI社員は
未配置で、Nova自身がこの領域を担う。

## Operations Division
Lead: Orion (COO)
Operations・Workflow・KPI・Quality・Reflectionを担当。Weekly Board Meeting
（Quest82）・KPI Alert（Quest78）・Reflection（Quest61）等の運用を統括する。
Quest106でQuality Team（後述）を新設し、Digital Asset Factoryの生成物に対する
機械的な品質チェックを担当させる。

## Memory & Intelligence
Lead: Cosmos (CIO)
Company Memory（Quest50）・Strategic Goal（Quest76）・KPI Memory（Quest58）・
Failed Decision Memory（Quest73）・Meeting Quality（Quest75）・Self Improvement
（Quest85）等、DAF自身の学習ループ全般を統括する。

## Digital Asset Factory
Executive Board全体、特にVega（Creative）・Atlas（Engineering）が共同で運用する
生産ライン。Project → Execution Plan → Creative Brief → Asset Generation
（Image Generation Service / Renderer） → Review → Publishの一連の流れ
（Quest90〜99で構築）。

# Quality Team（Quest106・Operations Division内）

Digital Asset Factoryの生成物（LINEスタンプ等）を、AI Reviewではなく
Pythonの決定的なルールだけで機械的にチェックするチーム
（`services/quality_control_service.py`）。DAF OSの「Lean AI First」
方針（Python → Rule Engine → Template → AI → CEOの優先順位）における、
最も安価で高速な先頭のPython層を担当する。Quest106時点では組織図・
ドキュメント上の役割分担の明文化のみで、実際のAgent分離は将来Questで行う。

# DAF Version

| バージョン | 期間 | 呼称 |
|---|---|---|
| DAF OS v1 | Quest1〜99 | Foundation Phase — パイプライン・基盤サービスの構築期 |
| DAF OS v2 | Quest100〜 | AI Company Phase — 会社としての体制・憲章が明文化された期 |

この「DAF OS v1 / v2」はdocs/organization.mdが定義する**会社としてのフェーズ**
を指し、README.md記載の技術的なバージョン番号（v0.1〜v2.6等、機能追加ごとの
リリース番号）とは別軸の分類である。
