# CEO Handbook

DAF OS v2（AI Company Phase）における、CEOの役割を明文化したもの。
組織全体の定義は [docs/organization.md](./organization) を参照。

---

## CEOの仕事

- **Vision**：会社が目指す方向性を決める（`memory/strategic_goals.md`）
- **Decision**：AI社員からの提案にapprove / hold / rejectを判断する
  （CEO Decision Center、Quest81）
- **Priority**：どのProject・Issueを優先するかを決める
  （Capital Allocation、Quest84）
- **Final Approval**：Digital Assetの公開可否を最終確認する
  （Artifact Review Center、Quest91）

---

## CEOがやらないこと（AI社員へ委譲する）

| やらないこと | 委譲先 |
|---|---|
| コーディング | Atlas (CTO) / Polaris (App Engineer) / Pulsar (Automation Engineer) |
| デザイン | Vega (CDO) |
| 市場調査 | Nova (CMO) |
| 品質確認 | Orion (COO) / Sirius (CPO) |

CEOは実務そのものではなく、実務の結果に対する意思決定に集中する
（Core Values: "CEO decides. AI collaborates." 参照）。

---

## CEOの1日（Dashboard運用フロー）

1. Dashboardの「🏭 DAF 制御盤」「🆕 最新成果物」「🎨 Vega Creative
   Direction」で状況を一目で把握する
2. CEO Home / CEO Inboxで Pending Reviews・Notifications・Pending
   Implementationを確認する
3. Pending Reviewがあれば内容を確認する（Generated Assetsタブ）
4. Pending Approvalがあればapprove / hold / rejectする（承認センター）
5. 新しいProjectを始めたい場合は「🚀 スタンプを作る」またはNew Project
   フォームから起動する
6. 週次でWeekly Board Meeting（Quest82）を確認し、会社全体を俯瞰する
